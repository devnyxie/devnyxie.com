#### Learning Resources

- [go101.org](https://go101.org/) - An up-to-date knowledge base for Go programming self learning.
- [gobyexample.com](https://gobyexample.com/) - An introduction to Go using annotated example programs.
- [Learn Go with tests](https://quii.gitbook.io/learn-go-with-tests) - Learn Go by writing tests.
- [Go Concurrency Exercises (GitHub)](https://github.com/loong/go-concurrency-exercises) - Exercises with real-life examples to study and practice Go concurrency patterns. Test-cases are provided to verify your answers.
- [Generic Go Exercises](https://exercism.org/tracks/go/exercises/) - Collection of exercises ranging from entry level up to advanced patterns.
- [Go Roadmap](https://roadmap.sh/golang) - Step by step "guide" to becoming a Go developer.
